# Разработка ПО для охраны лаборатории робототехники с помощью робота-собаки в автономном режиме 

**Разработка ПО для охраны лаборатории робототехники с помощью робота-собаки в автономном режиме** — это продвинутый учебный комплекс, ориентированный на освоение основ мобильной робототехники, компьютерного зрения и автономного патрулирования на **реальном оборудовании** (робот-собака). 

---

##  Структура учебного проекта
Проект разделен на три логических этапа, которые ведут пользователя от настройки аппаратной части до создания автономного охранного агента, способного работать в реальной лаборатории.

| Этап | Название лабораторной работы | Ключевая технология | Результат |
| :--- | :--- | :--- | :--- |
| **ЛР №1** | **Настройка сенсоров и видеопотока** | `OpenCV`, `ROS Distributed` | Мониторинг видеопотока с камеры робота-собаки |
| **ЛР №2** | **Детекция движения** | `Frame Difference`, `Background Subtraction` | Автономное обнаружение вторжения в лабораторию |
| **ЛР №3** | **Система оповещения и автономный режим** | `Python API`, `Logging`, `Sound Alert` | Скрипт автономной охраны с звуковым сигналом |

---

##  Технологический стек (Hardware)
* **Control PC:** Ubuntu 20.04 / Windows 10 + ROS Noetic (вычисления, обработка видео и визуализация).
* **Robot Platform:** Робот-собака (Unitree Go1 / CyberDog / аналог) с встроенной камерой.
* **Embedded:** Встроенный контроллер робота для низкоуровневого управления движением.
* **Сенсоры:** RGB-камера (основной источник), IMU, энкодеры сервоприводов.
* **Связь:** HTML / USB (для передачи видеопотока и команд управления).

---

##  Настройка среды и сетевого взаимодействия

В отличие от симуляции, работа с реальным роботом-собакой требует настройки видеопотока и распределенной обработки данных.

### 1. Подготовка Remote PC 
Установите пакеты для обработки видео и управления:
```bash
sudo apt update
pip install opencv-python numpy pygame
# Для ROS (опционально)
sudo apt install ros-noetic-cv-bridge ros-noetic-usb-cam
```

### 2. Настройка доступа к видеопотоку 
Обеспечьте стабильный доступ к камере робота-собаки. 
#### На вашем ПК (Remote PC):
```bash
export CAMERA_INDEX=0  # или IP камеры
export ROBOT_IP=<IP_РОБОТА_СОБАКИ>
```
#### При подключении через ROS (если поддерживается):
```bash
export ROS_MASTER_URI=http://<IP_РОБОТА>:11311
export ROS_HOSTNAME=<IP_ВАШЕГО_ПК>
```
